## Важливо: масштабування вузлів через Terraform не працює

Під час підготовки з'ясувалось: у модулі `terraform-aws-modules/eks` (v21)
для керованих груп вузлів `scaling_config[0].desired_size` стоїть у
`lifecycle.ignore_changes`. Тому `terraform apply -var node_desired_size=0/1`,
як у README і матеріалах занять 8–9, кількість вузлів після створення групи
**не змінює**. План просто не покаже змін.

У матеріалах заняття 10 вузли піднімаються й опускаються так:

```bash
NG=$(aws eks list-nodegroups --cluster-name <prefix>-eks --query 'nodegroups[0]' --output text)
aws eks update-nodegroup-config --cluster-name <prefix>-eks --nodegroup-name $NG --scaling-config desiredSize=1
```

На слайді 4 є коротке виправлення для студентів. README варто поправити
так само: розділ «Режим життя кластера».

## Що варто дописати в README вручну

- У перелік тек додати `infrastructure/` і `docs/`.
- Посилання на `docs/lesson-10.md`.
- У розділ «Пастки» додати пункт про порядок прибирання: спочатку сервіс
  `web-public`, потім вузли, і ніколи `destroy` кластера з живим NLB.

## Що перевірено

- `kustomize build` обох тек: у стані «як поставлено» та з усіма
  розкоментованими рядками.
- `kubeconform -strict` проти схем Kubernetes 1.34 і схем CRD
  (`HelmRelease` v2, `HelmRepository` v1, `SecretStore`/`ExternalSecret` v1):
  14 об'єктів, 0 помилок.
- `tofu fmt -check` і розбір HCL усіх `.tf`.
- **Не перевірено:** `terraform validate` проти схеми провайдера (реєстр
  провайдерів недоступний із середовища збирання) і справжній запуск на
  акаунті Free plan. Перед заняттям варто один раз прогнати на своєму акаунті.

## Припущення, які варто звірити

- Під час заняття вузол **один** (`desiredSize=1`), як на занятті 9.
- У групі вузлів `min_size = 0` і `max_size` не менше 1 — інакше `desiredSize=0` відхилиться.
- У `cluster/` вже є `var.prefix`, `var.region`, `local.common_tags`
  і `module.eks` — саме на них посилається `platform-iam.tf`.
- У `flux/` вже є `data.aws_eks_cluster.this` і змінні `cluster_name`,
  `region`, `git_url`, `git_branch`, `sync_interval`.
